# Random Jokes Generator

This is a simple web application that generates random jokes using the [Official Joke API](https://official-joke-api.appspot.com/). The user can click a button to get a new joke, which consists of a setup and a punchline.

## Features
- Fetches random jokes from an API.
- Displays the setup and punchline of the joke.

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
